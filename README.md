# virtual-cv

This repository contains the source code for my personal Virtual CV and portfolio website.
The website was built as a virtual CV and it will be updated as I complete new projects
and develop my skills.

## Live Website
https://francoet.github.io/virtual-cv/

## Technologies that were used
HTML5
CSS3
JavaScript
Git
GitHub Pages

## Features
-Sticky navigation menu
-Responsive desktop, tablet and mobile layout
-Personal introduction
-Technical skills overview
-Academic and personal project cards
-University and high-school education details
-Contact links for email, GitHub and LinkedIn
-Automaticaly updated footer year
-Smooth Scrolling betwen sections

# Status of the Project
The site is still under development
